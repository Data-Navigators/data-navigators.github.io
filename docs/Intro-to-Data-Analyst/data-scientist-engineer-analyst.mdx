# Data Roles & Responsibilities

## Roles and primary focus

| Role | Primary Question Answered | Primary Tools | Core Focus |
| --- | --- | --- | --- |
| **Data Engineer (DE)** | "How do we reliably move and store data?" | SQL, Spark, Airflow, Snowflake, dbt | Data pipelines, infrastructure, clean schemas |
| **Data Analyst (DA)** | **"What happened and why should business care?"** | **SQL, Tableau/PowerBI, Python/DuckDB** | **Business KPIs, metrics, storytelling, insights** |
| **Data Scientist (DS)** | "What will happen and what pattern exists?" | Python, R, Scikit-learn, Statistics | Predictive modeling, experimentation, ML |
| **ML Engineer (MLE)** | "How do we run ML models in production?" | Docker, Kubernetes, MLOps, APIs | Scalability, latency, model deployment |

This section is used to represent how role boundaries typically lie. Boundaries depend on the client, team structure, and the lens being used — treat this table as a general guideline rather than a strict rule.
